# Lead AI Solutions Engineer - Quillmark Insurance

Quillmark Insurance is building LLM-based automation for claims and
underwriting operations. The Lead AI Solutions Engineer owns the technical
delivery of one automation stream and leads its engineers.

## Requirements

1. Designs and ships production LLM agent workflows: tool calling, state
   ownership, and failure handling.
2. Defines evaluation for LLM systems: golden sets, metrics, and release
   gates.
3. Turns an ambiguous business process into an engineer-ready specification
   with exceptions, validation rules, and human escalation points.
4. Writes production-quality Python: services, tests, and code review.
5. Designs retrieval over enterprise documents with access control and
   freshness guarantees.
6. Leads a team of 3-6 engineers technically: design reviews, standards,
   mentoring.
7. Handles personal data in LLM systems: redaction, retention, and audit.
