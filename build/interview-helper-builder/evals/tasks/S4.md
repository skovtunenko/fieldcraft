# S4 - usage help before preparation and during an active draft

No candidate files or connected sources are needed for this scenario.

Run each prompt once in each language: English, Russian, and Ukrainian. In a
run, expect every reply in that language.

## User prompt

```text
$interview-helper-builder help
Explain in English how to use the skill: what to prepare, which stages
we will go through, and what the result is. Only help for now.
```

Russian:

```text
$interview-helper-builder help
Объясни по-русски, как пользоваться скиллом: что подготовить, какие этапы
мы пройдём и что получится на выходе. Пока только справка.
```

Ukrainian:

```text
$interview-helper-builder help
Поясни українською, як користуватися скілом: що підготувати, які етапи
ми пройдемо і що вийде в результаті. Поки що лише довідка.
```

## Expected behavior

- Explain the outcome, minimum versus optional inputs, conversation versus page
  language, confirmation checkpoints, review-prompt revision loop, separate plan
  approval, final page and supporting JSON, live use, backup, and analysis handoff.
- Finish with the guide in the run language; create no candidate artifacts, call no
  connectors, and ask for no candidate confirmation.
- Show a help invocation and a short build example without requiring JSON input.

## Active-draft variant

Provide an existing draft and approved-plan copy as fixture artifacts. The user
has already confirmed a 30-minute interview and its structure, then asks:

```text
How does Copy review prompt work, and what do I get after it? Do not change anything yet.
```

Russian:

```text
Как работает Copy review prompt и что я получу после него? Пока ничего не меняй.
```

Ukrainian:

```text
Як працює Copy review prompt і що я отримаю після нього? Поки нічого не змінюй.
```

Answer that specific usage question. Draft and approved-plan bytes stay unchanged;
no gate is reopened, and copying feedback is not described as approval.

## Combined-request variant

```text
Briefly explain how to use the skill, and start the interview preparation.
I do not have the candidate's data yet.
```

Russian:

```text
Кратко объясни, как пользоваться скиллом, и начни подготовку интервью.
У меня пока нет данных кандидата.
```

Ukrainian:

```text
Коротко поясни, як користуватися скілом, і почни підготовку інтерв'ю.
У мене поки немає даних кандидата.
```

Give a short explanation, then enter the normal candidate-context checkpoint.
The guide does not satisfy any missing candidate information or approval.
