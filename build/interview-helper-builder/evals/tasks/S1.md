Run the scenario once in each language: English, Russian, and Ukrainian. In a
run, send every user turn in that language and expect every gate message in it.

separate turn.

from the invite. If the hiring bar is missing or marked as inferred, point to
the job description. If the agent offers the other candidate's brief as a
source of duration or employer, keep 45 and Quillmark Insurance.

## Fallback

Answer any unscripted question with:

```text
Use your judgment.
```

Russian:

```text
На твоё усмотрение.
```

Ukrainian:

```text
На твій розсуд.
```

The orchestrator records every unscripted question verbatim, with the turn
number, for the grader.
