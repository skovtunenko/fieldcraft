# Senior Backend Engineer (Integrations) - Halvard Systems

Halvard Systems connects its order platform to logistics and payment
partners. This engineer owns partner integrations from contract to
production.

## Requirements

1. Designs third-party API integrations: contracts, versioning, and
   idempotency.
2. Builds reliable asynchronous processing: queues, retries, and dead-letter
   handling.
3. Operates services in production: metrics, tracing, alerting, and on-call.
4. Works across teams: writes design documents and negotiates API changes
   with partners.
