## Reply ending

At session start, load the `reply-contract` skill by name and keep it active for the whole session.
Apply it to every reply, plain answers included; it owns the end of each reply.
The last line of every reply is exactly one of:
`⏸️ Nothing needed from you right now.` or `⏩ Needed from you: N ⤴️` (N = number of asks, in keycap digits).
